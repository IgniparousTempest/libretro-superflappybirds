# Super Flappy Birds artwork

Original artwork for launchers, game libraries and frontends on any platform.

The [cover](cover.png), [box front](box-front.png), [back](box-back.png),
[spine](box-spine.png) and [3D box](box-3d.png) are saved at their original
render resolution. The [box texture](box-texture.png) joins the back, spine
and front panels at full resolution.

The [logo](logo.png) and [creator credit](credit-courtney-pitcher.png) preserve
the title-screen lettering at its native pixel size. The [bird icon](bird-icon.svg)
is a scalable SVG using `currentColor`.

Original screenshots are in [`.readme`](../.readme/). See [LICENSE](../LICENSE).
